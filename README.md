## About the Project

**Indian Independence Day 2026** is a beginner-friendly frontend project created using **HTML5, CSS3, and JavaScript** to celebrate India's **80th Independence Day** on **15 August 2026**.

The project presents a beautifully designed **Indian National Flag** along with Independence Day messages, patriotic visuals, simple animation, and basic JavaScript interactions.

The main purpose of this project is to practice the fundamentals of frontend development by combining **HTML5, CSS3, and JavaScript** in one simple and meaningful project.

---

## Project Objective

The objective of this project is to create a simple and attractive Independence Day webpage while understanding how the three core frontend technologies work together.

### The project focuses on:

- Creating webpage structure using HTML5
- Designing the webpage using CSS3
- Creating the Indian National Flag using HTML and CSS
- Adding simple animation using CSS3
- Adding interaction using JavaScript
- Practicing basic DOM manipulation
- Understanding JavaScript event handling
- Building a complete beginner-level frontend project

## Indian National Flag

The main attraction of this project is the **Indian National Flag**.

The flag contains three horizontal bands:

### Saffron

Saffron represents **courage and sacrifice**.

### White

White represents **peace and truth**.

### Green

Green represents **growth and prosperity**.

### Ashoka Chakra

The **Ashoka Chakra** is placed at the center of the white band and is represented using **Navy Blue**.

### Project Colour Values

```text
Saffron       #FF9933
White         #FFFFFF
Green         #138808
Ashoka Blue   #000080
```

These colours are used throughout the project to maintain the Indian National Flag theme.
