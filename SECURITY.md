# Security Policy

## About This Project

Indian Independence Day 2026 is a beginner-friendly frontend project developed using HTML5, CSS3, and JavaScript.

The project is intended for educational and demonstration purposes.

## Supported Version

The latest version of the project available on the `main` branch is considered the supported version.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older versions | No |

## Reporting a Security Issue

If you discover a potential security vulnerability, security issue, or other concern related to this repository, please report it privately to the repository maintainer rather than publicly posting the details in an issue.

Please contact the repository maintainer through GitHub with the following information:

- A clear description of the issue
- Steps to reproduce the issue
- The affected file or component
- Any relevant screenshots or examples
- Any suggested solution, if available

## Responsible Disclosure

Please avoid publicly disclosing security vulnerabilities before they have been reviewed.

Providing sufficient information to reproduce the issue will help with investigation and resolution.

## Scope

This security policy applies to the source code and project files contained in this repository.

Thank you for helping keep this project secure and reliable.
